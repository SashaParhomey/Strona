# 🚗 Прокат Автомобілів - Веб-сайт резервування

Повнофункціональний веб-сайт для управління резерваціями автомобілів, побудований на PHP, HTML, CSS та JSON.

## 📋 Вимоги до проекту

1. ✅ Логування / реєстрація
2. ✅ Виведення поточних резервацій
3. ✅ Перегляд доступного обладнання
4. ✅ Можливість зарезервувати обладнання
5. ✅ Скасування резервацій
6. ✅ Запам'ятовування залогованого користувача
7. ✅ Можливість виходу користувача

## 🚀 Установка та запуск

### Вимоги
- XAMPP (або будь-який локальний PHP сервер)
- PHP 7.4+

### Кроки установки

1. **Завантажте XAMPP** (якщо ще не встановлено)
   - Завантажте з https://www.apachefriends.org/
   - Встановіть програму

2. **Помістіть проект в XAMPP**
   - Проект уже розташований у `c:\xampp\htdocs\Strona samochod\`
   - Всі файли вже створені

3. **Запустіть XAMPP**
   - Відкрийте XAMPP Control Panel
   - Натисніть "Start" поруч з Apache та MySQL

4. **Отримайте доступ до сайту**
   - Відкрийте браузер
   - Перейдіть на `http://localhost/Strona%20samochod/`
   - Вас автоматично перенаправить на сторінку логування

## 🎨 Функціональність

### 1. Аутентифікація
- **Реєстрація:** Нові користувачі можуть зареєструватися
- **Логування:** Захищене логування з хешуванням пароля (bcrypt)
- **Сессія:** Запам'ятовування користувача через сессії PHP
- **Вихід:** Очищення сессії при виході

### 2. Управління автомобілями
- Перегляд всіх доступних автомобілів
- Фільтрування недоступних транспортних засобів
- Детальна інформація про кожен автомобіль

### 3. Резервації
- **Створення:** Вибір дат та бронювання
- **Перегляд:** Список всіх резервацій користувача
- **Скасування:** Можливість скасувати підтверджену резервацію
- **Розрахунок:** Автоматичний розрахунок ціни

### 4. Профіль користувача
- Перегляд інформації профілю
- Редагування імені та номеру телефону
- Захист електронної пошти від змін

## 🔒 Безпека
