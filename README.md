# 🚗 Strona — прокат автомобілів

Веб-сайт для бронювання автомобілів на PHP: реєстрація та вхід, каталог авто за категоріями, бронювання на дати, перелік і скасування власних резервацій, профіль користувача. Інтерфейс трьома мовами: польська (за замовчуванням), англійська, українська.

## Можливості

- Реєстрація та вхід (паролі зберігаються як хеші `password_hash`)
- Каталог: 4 категорії (економ, комфорт, люкс, мотоцикли), сортування за ціною, роком, кількістю місць
- Бронювання з перевіркою зайнятих дат і розрахунком ціни
- Мої резервації та скасування майбутніх бронювань
- Профіль (ім'я, телефон)
- Перемикач мови `PL / EN / UK` (або `?lang=uk` у будь-якій адресі)

## Запуск

Потрібен PHP 8.0+.

```bash
php -S 0.0.0.0:5000 router.php
```

Відкрийте http://localhost:5000. На Replit кнопка **Run** робить те саме.

`router.php` обов'язковий для вбудованого сервера PHP: він закриває доступ до `data/`, `includes/` та службових файлів. На Apache (XAMPP, хостинг) цю роль виконують файли `.htaccess`.

При першому запуску файли `data/users.json` і `data/reservations.json` створюються автоматично. Вони не зберігаються в git, бо містять особисті дані.

## Зберігання даних

Усі дані лежать у JSON-файлах у папці `data/`. Кожна зміна (реєстрація, бронювання, скасування, редагування профілю) виконується під файловим блокуванням, тому одночасні запити не перезаписують один одного, а одне авто не можна забронювати двічі на ті самі дати.

Дата повернення не вважається зайнятою: якщо авто повертають 15-го, з 15-го його можна бронювати знову.

## Як додати автомобіль

1. Покладіть фото в `images/` (PNG/JPG, бажано до ~300 КБ).
2. Додайте запис у `data/vehicles.json`:

```json
{
  "id": "audi_001",
  "name": "Audi A6",
  "brand": "Audi",
  "model": "A6",
  "year": 2024,
  "license_plate": "WA12345",
  "status": "available",
  "price_per_day": 280,
  "fuel_type": "Diesel",
  "seats": 5,
  "transmission": "Automatic",
  "image": "audia6.png",
  "category": "comfort"
}
```

`id` має бути унікальним. `category`: `economy`, `comfort`, `luxury` або `motorcycle`.

## Як додати переклад

Додайте ключ в усі три файли `includes/langs/en.php`, `pl.php`, `uk.php` і використовуйте його в коді як `t('ключ')`.

## Безпека

- CSRF-токен у кожній формі; скасування та вихід лише через POST
- Новий ID сесії після входу, cookie сесії `HttpOnly` + `SameSite=Lax`, автоматичний вихід після години неактивності
- Однакове повідомлення про помилку для невідомого email і невірного пароля
- Мова з cookie перевіряється за списком дозволених
- Прямий доступ до `data/` та `includes/` заборонено
