# 📁 Путівник по файлам проекту

## 🎯 Коротко

Це веб-приложение для резервування автомобілів на PHP + JSON.

---

## 📋 ОСНОВНІ СТОРІНКИ (відображаються користувачеві)

### 🔓 Без логування потрібні

#### [login.php](login.php)
- **Призначення:** Логування в систему
- **Форма:** Email + пароль
- **Результат:** Встановлення сессії
- **Перенаправляє:** На `index.php` при успіху

#### [register.php](register.php)
- **Призначення:** Реєстрація нового користувача
- **Форма:** Ім'я + Email + Телефон + Пароль
- **Валідація:** Email унікальний, пароль 6+ символів
- **Результат:** Додається до `data/users.json`

---

### 🔐 Потребують логування

#### [index.php](index.php)
- **Призначення:** Головна/Дашбоард сторінка
- **Містить:** 3 карточки навігації
- **Доступні дії:** Перейти до Автомобілів, Резервацій, Профілю

#### [vehicles.php](vehicles.php)
- **Призначення:** Список всіх автомобілів
- **Сітка:** Карточки автомобілів
- **Інформація:** Марка, модель, рік, палива, місця, ціна
- **Кнопка:** "Зарезервувати" → Перенаправляє на `reserve.php?id=...`

#### [reserve.php](reserve.php?id=vehicle_001)
- **Призначення:** Форма резервації конкретного автомобіля
- **Деталі:** Повна інформація про автомобіль
- **Форма:** Вибір дат (від/до)
- **Розрахунок:** Автоматичний расчунок цены (дні × ціна/день)
- **Валідація:** Перевірка наявності конфліктів дат
- **Результат:** Додається до `data/reservations.json`

#### [reservations.php](reservations.php)
- **Призначення:** Мої резервації
- **Список:** Все резервації користувача
- **Інформація:** Автомобіль, дати, статус, ціна
- **Дії:** 
  - Перегляд деталей
  - Скасування (змінює статус на "cancelled")

#### [profile.php](profile.php)
- **Призначення:** Профіль користувача
- **Редагування:**
  - ✏️ Ім'я (можна змінити)
  - ✏️ Телефон (можна змінити)
  - 🔒 Email (не можна змінити)
- **Результат:** Зміни зберігаються в `data/users.json`

## 🔧 ВНУТРІШНІ ФАЙЛИ

### 📦 [includes/config.php](includes/config.php)
**Конфігурація та функції ядра**

Константи:
- `DB_DIR` - Шлях до папки з даними
- `USERS_FILE` - Шлях до users.json
- `VEHICLES_FILE` - Шлях до vehicles.json
- `RESERVATIONS_FILE` - Шлях до reservations.json

Функції:
- `loadJSON($filepath)` - Завантажує JSON
- `saveJSON($filepath, $data)` - Зберігає JSON
- `isLoggedIn()` - Перевірка сессії
- `getCurrentUser()` - Отримати юзера з сессії
- `hashPassword($password)` - Хешування (bcrypt)
- `verifyPassword($password, $hash)` - Перевірка пароля
- `generateID()` - Генерація унікального ID
- `redirect($url)` - Перенаправлення

### 🎨 [includes/header.php](includes/header.php)
**Верхня навігаційна панель**

Містить:
- Логотип сайту
- Меню навігації (Головна, Автомобілі, Резервації, Профіль)
- Інформація про юзера
- Кнопка виходу (Logout)

Включається на кожну сторінку: `<?php include 'includes/header.php'; ?>`

### 📜 [includes/footer.php](includes/footer.php)
**Нижній колонтитул**

Містить:
- Про компанію
- Контакти (телефон, email)
- Години роботи
- Копірайт

Включається на кожну сторінку: `<?php include 'includes/footer.php'; ?>`

## 🔄 ЖИТТЄВИЙ ЦИКЛ РЕЗЕРВАЦІЇ

1. **Користувач логується** → `login.php` встановлює сессію
2. **Переходить на Автомобілі** → `vehicles.php` показує список
3. **Вибирає автомобіль** → `reserve.php?id=...` показує форму
4. **Вибирає дати** → Перевіряється наявність конфліктів
5. **Натискає Зарезервувати** → POST запит в `reserve.php`
6. **Резервація створена** → Додається в `data/reservations.json`
7. **Перенаправляє** → На `reservations.php`
8. **Може скасувати** → Клік на кнопку "Скасувати" → `api/cancel_reservation.php`
9. **Статус змінюється** → На "cancelled" в JSON файлі

## 🚀 ГОТОВІ ТЕСТОВІ СЦЕНАРІЇ

### Тест 1: Логування
1. Перейти на `http://localhost/Strona%20samochod/`
2. Email: `test@example.com`
3. Пароль: `password`
4. Натиснути "Логування"
5. ✅ Повинна показатись головна сторінка

### Тест 2: Резервація
1. На головній натиснути "Переглянути автомобілі"
2. Вибрати автомобіль
3. Натиснути "Зарезервувати"
4. Вибрати дати (наприклад, 10-15 січня)
5. Натиснути "Зарезервувати"
6. ✅ Повинна показатись сторінка з успіхом

### Тест 3: Скасування
1. На головній натиснути "Мої резервації"
2. Натиснути "Скасувати"
3. Підтвердити скасування
4. ✅ Статус повинен змінитись на "Скасована"
