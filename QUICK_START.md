# 🎯 ШВИДКИЙ СТАРТ - 3 ХВИЛИНИ

## ⚡ Швидкий запуск

### 1. Запустіть XAMPP
- Знайдіть та відкрийте **XAMPP Control Panel** на комп'ютері
- Натисніть **START** біля **Apache**
- Натисніть **START** біля **MySQL**
- Очікуйте поки напишеться **Running**

### 2. Відкрийте сайт
- Відкрийте браузер (Chrome, Firefox, Edge)
- Введіть: `http://localhost/Strona%20samochod/`
- Натисніть Enter

### 3. Логуйтесь
- **Email:** test@example.com
- **Пароль:** password
- Натисніть "Логування"

## 🤔 Щось не працює?

### Apache не запускається?
→ Можливо порт 80 занятий. Закрийте інші програми та спробуйте знову.

### "Сторінка не знайдена"?
→ Переконайтесь що адреса правильна: `http://localhost/Strona%20samochod/`

### Не можу залогуватися?
→ Спробуйте зареєструватися з новим email через сторінку реєстрації.

## 🎨 Що бачите на сайті?

### Головна сторінка (index.php)
- Привітання користувача
- 3 карточки (Автомобілі, Резервації, Профіль)

### Автомобілі (vehicles.php)
- Список всіх автомобілів
- Кнопка "Зарезервувати" для кожного
- Статус доступності

### Резервація (reserve.php)
- Вибір дат (від якого дня до якого)
- Автоматичний розрахунок ціни
- Кнопка "Зарезервувати"

### Мої резервації (reservations.php)
- Список всіх ваших резервацій
- Статус кожної (підтверджена/скасована)
- Кнопка "Скасувати" для активних резервацій

### Профіль (profile.php)
- Ваша електронна пошта (не змінюється)
- Ім'я (можна змінити)
- Телефон (можна змінити)

## 💾 Де зберігаються дані?

Проект використовує **JSON файли** замість бази даних:

```
data/
├── users.json           → Користувачі
├── vehicles.json        → Автомобілі
└── reservations.json    → Резервації
```

Все автоматично зберігається, перепочинувати не потрібно.
