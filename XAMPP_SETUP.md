# 🚀 Гайд запуску на XAMPP

## Крок 1: Завантаження та установка XAMPP

### Для Windows:
1. Перейдіть на https://www.apachefriends.org/
2. Натисніть "Download" (версія для Windows)
3. Запустіть інсталер (XAMPP-windows-x64-...)
4. Встановіть у директорію за замовчуванням (`C:\xampp`)
5. Дозвольте встановлення Apache та MySQL

## Крок 2: Запуск XAMPP

1. Знайдіть "XAMPP Control Panel" у меню Пуск
2. Натисніть "Start" поруч з **Apache** ✓
3. Натисніть "Start" поруч з **MySQL** ✓

```
Apache: Running
MySQL:  Running
```

Якщо будуть помилки портів, дивіться розділ "Розв'язання проблем".

## Крок 3: Розташування файлів

Проект **вже розташований** в правильній папці:
```
C:\xampp\htdocs\Strona samochod\
```

Структура:
```
xampp/
├── htdocs/
│   └── Strona samochod/      ← Ваш проект тут!
│       ├── index.php
│       ├── login.php
│       ├── css/
│       ├── includes/
│       ├── api/
│       ├── data/
│       └── README.md
```

## Крок 4: Доступ до сайту

1. Відкрийте браузер (Chrome, Firefox, Edge)
2. Введіть адресу:
   ```
   http://localhost/Strona%20samochod/
   ```
   або
   ```
   http://127.0.0.1/Strona%20samochod/
   ```

3. Вас автоматично перенаправить на `login.php`

## Крок 5: Логування

### Готовий тестовий акаунт:
- **Email:** `test@example.com`
- **Пароль:** `password`

### Або створіть новий акаунт:
1. На сторінці логування натисніть "Зареєструйтеся"
2. Заповніть форму реєстрації
3. Натисніть "Зареєструватися"
4. Логуйтесь з новим акаунтом

## ✅ Перевірка установки

1. **Apache запущено?** - Почніть Apache в XAMPP Control Panel
2. **Доступ по URL?** - Перейдіть на `http://localhost/Strona%20samochod/`
3. **База даних створена?** - Папка `data/` автоматично створює JSON файли

## 🔧 Розв'язання проблем

### Проблема: Apache не запускається
**Рішення:**
1. Перевірте чи порт 80 вільний (інші программи можуть його займати)
2. Змініть порт в `xampp/apache/conf/httpd.conf`
3. Або закрийте програми що користуються портом 80

### Проблема: "Сторінка не знайдена" (404)
**Рішення:**
1. Переконайтесь що URL правильний: `http://localhost/Strona%20samochod/`
2. Переконайтесь що файли в правильній папці
3. Очистіть кеш браузера (Ctrl+Shift+Delete)

### Проблема: Помилка "Call to undefined function"
**Рішення:**
1. Переконайтесь що PHP версія 7.4+ (проверить в XAMPP)
2. Перезапустіть Apache

### Проблема: Помилка при записі в базу даних
**Рішення:**
1. Дайте дозвіл на запис у папку `data/`:
   - Клікніть правою кнопкою на папку
   - Властивості → Безпека → Редагувати
   - Надайте повні дозволи

### Проблема: "Аріантус класу" при реєстрації
**Рішення:**
1. Email вже зареєстрований
2. Спробуйте інший email

## 🌐 Доступ з інших пристроїв

### З іншого комп'ютера в мережі:
1. Дізнайтесь IP вашого комп'ютера:
   - Windows: `ipconfig` (шукайте IPv4)
   - Наприклад: `192.168.1.100`

2. На іншому пристрої перейдіть:
   ```
   http://192.168.1.100/Strona%20samochod/
   ```

### З мобільного телефону:
1. Підключітесь до тієї ж Wi-Fi мережі
2. Перейдіть на `http://192.168.1.100/Strona%20samochod/`

## 🔒 Базова безпека (рекомендації)

Для локального тестування вищезазначені установки достатні.

Для продакшену (публічний сервер):

2. Використовуйте HTTPS замість HTTP

4. Перейдіть на професійний хостинг
