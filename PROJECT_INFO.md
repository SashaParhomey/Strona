# 🏆 Проект: ПРОКАТ АВТОМОБІЛІВ

**Статус:** ✅ Готовий до використання  
**Версія:** 1.0.0  
**Дата створення:** Січень 2025  
**Мова:** PHP 7.4+ / HTML5 / CSS3  
**База даних:** JSON (без MySQL)  

---

## 📌 Про проект

Повнофункціональна веб-система для управління прокатом автомобілів. Дозволяє користувачам реєструватися, переглядати доступні автомобілі, робити резервації та управляти ними.

**Розроблено для:** XAMPP локальний сервер  
**Мова інтерфейсу:** Українська, Польська  
**Тип:** Web Application
